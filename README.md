# 🎶 vinyl_pipeline - Split Vinyl Recordings Easily

## 📚 Overview
vinyl_pipeline is a simple tool designed to help you split vinyl recordings into individual tracks. It automatically detects silence between tracks, making your listening experience smoother. This application is written in pure Go, which means you don’t need any additional libraries or software like FFmpeg. It comes as a single binary, simplifying the installation process.

## 🎼 Features
- **Silence Detection**: Automatically identifies silence to split tracks accurately.
- **Multiple Formats Supported**: Processes audio files in WAV and FLAC formats.

## 🔧 Usage Instructions
To split a vinyl recording:
1. Launch the application.
2. Click on the "Load File" button and select your audio file.
3. Adjust the silence detection settings if needed. The defaults work well for most recordings.
4. Click "Process" to begin splitting your audio.
5. Once complete, save your tracks to your preferred directory.
